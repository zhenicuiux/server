# راهنمای جامع و گام‌به‌گام راه‌اندازی سرور در `Serv00.com`

سرویس `Serv00` یک هاست لینوکسی/یونیکسی رایگان مستقر در لهستان است که امکانات یک سرور ابری را به شکل رایگان و بدون نیاز به کارت اعتباری بین‌المللی در اختیارتان قرار می‌دهد.

---

## ۱. مراحل ثبت‌نام و فعال‌سازی

۱. وارد وب‌سایت [Serv00.com](https://www.serv00.com/) شوید.
۲. روی دکمه ثبت‌نام کلیک کنید.
۳. نام کاربری (`Username`)، ایمیل معتبر و پاسخ سوال امنیتی را وارد کنید. (ترجیحاً در زمان ثبت‌نام از فیلترشکن پایدار خارجی استفاده کنید).
۴. ایمیل فعال‌سازی حاوی اطلاعات زیر برایتان ارسال می‌شود:
   - نام سرور: مثلاً `s12.serv00.com`
   - نام کاربری: `your_username`
   - رمز عبور اولیه: `your_password`
   - آدرس پنل مدیریت وب: `https://panel12.serv00.com/`

---

## ۲. فعال‌سازی قابلیت اجرای برنامه‌های شخصی (`Run own applications`)

برای این‌که بتوانید ربات تلگرام، وب‌سرویس پایتون یا نودجی‌اس ران کنید، باید این گزینه را فعال کنید:
۱. وارد پنل کاربری وب شوید.
۲. به بخش **Additional services** بروید.
۳. تب **Run own applications** را پیدا کرده و وضعیت آن را روی **Enabled** قرار دهید.
*(این کار به شما اجازه می‌دهد پروسه‌های پس‌زمینه نظیر بات‌ها و برنامه‌های اختصاصی پایتون یا نود را بدون توقف اجرا کنید).*

---

## ۳. اتصال از طریق خط فرمان و ترمینال (`SSH`)

از طریق ترمینال ویندوز (PowerShell یا CMD) یا نرم‌افزارهای `PuTTY` و `Termius` می‌توانید متصل شوید:

```bash
ssh your_username@s12.serv00.com
```
رمز عبور دریافتی در ایمیل را وارد نمایید.

---

## ۴. رزرو پورت اختصاصی برای وب‌سایت و داشبورد

در `Serv00` ابزاری به نام `devil` برای مدیریت سرور وجود دارد. برای راه‌اندازی وب‌سرویس نیاز به یک پورت آزاد دارید:

```bash
devil port add tcp random
```
سیستم یک شماره پورت (مثلاً `28451`) به شما اختصاص می‌دهد. این پورت اختصاصی شما خواهد بود.

---

## ۵. اجرای هم‌زمان وب‌سایت، داشبورد و ربات تلگرام با `PM2`

برای این که وب‌سایت و ربات تلگرام شما به خواب نروند و پس از بستن ترمینال کماکان ۲۴ ساعته فعال بمانند، از ابزار `PM2` استفاده می‌کنیم:

```bash
# نصب محلی pm2
npm install -g pm2

# بررسی مسیر نصب
which pm2
```

سپس برنامه‌های خود را به صورت پس‌زمینه اجرا می‌کنید:

```bash
# اجرای ربات تلگرام
pm2 start bot.py --name "telegram-bot" --interpreter python3

# اجرای داشبورد و وب‌سایت
pm2 start main.py --name "web-dashboard" --interpreter python3

# ذخیره لیست پروسه‌ها برای شروع خودکار
pm2 save
```

---

## ۶. نگهداری و تمدید خودکار (جلوگیری از غیرفعال شدن ۹۰ روزه)

سیاست سرویس `Serv00` این است که حساب کاربری نباید ۹۰ روز بدون لاگین رها شود. برای آسودگی خاطر:
- می‌توانید هر چند ماه یک‌بار وارد پنل کاربری شوید.
- یا از اسکریپت اکشن گیت‌هاب که در این ریپازیتوری در مسیر `.github/workflows/keep_alive_ping.yml` قرار داده شده استفاده کنید تا به صورت خودکار ماهانه یک پینگ و لاگین `SSH` برقرار کند.
